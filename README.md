## City Voice-Local Issue Reporting System
A simple web app for Ulaanbaatar residents to report local issues with photos and locations, while admins manage the reports.
   

## Tech Stack
  * Language: TypeScript
  * Framework: Next.js(app router)
  * Styling Tailwind CSS
  * Database & ORM: PostgreSQL & Prisma
  * Authentication: Clerk Auth
  * Deployment: Vercel

 ## Features
  * Location Tagging: Pinpoint-map.
  * Photo Uploads: Attach images to show proof the problem.
  * Authentication: Secure user sessions and protected routes Clerk.
  * Admin Dashboard: A special some area for admins to view and manage incoming reports.
  * Responsive Design: Looks great on phones, tables and computers.
